Quality dimension 
Modelni katta dataset bilan train qildi degani har doim ham yaxshi model boladi degani emas.chunki dataset katta bolsa ham toza bolmasa model yaxshi model bolmaydi.
Common crawl ni tozalab clean,filter qilib, deduplicate qilib FineWeb holiga keltirish yetarlimi.yoq data toza va yaxshi bolishi uchun yana boshqa narsalar ham bor. Data yaxshi bolishi uchun dataga turli xil savollar berib korishimiz kerak.

Quality Dimensions — bu ma’lumot yoki datasetning sifatini baholash uchun ishlatiladigan asosiy mezonlar.
Ya’ni savol shunday:
“Bu data qanchalik yaxshi?”
Bunga faqat bitta mezon bilan emas, bir nechta o‘lchov bilan javob beriladi. Shu o‘lchovlar quality dimensions deyiladi.
Masalan LLM datasetida eng ko‘p uchraydiganlari:
Accuracy — ma’lumot qanchalik to‘g‘ri?
Completeness — ma’lumot yetarlimi yoki nimadir yetishmayaptimi?
Consistency — bir joydagi ma’lumot boshqa joy bilan zid emasmi?
Relevance — taskga aloqadormi?
Diversity — ma’lumotlar xilma-xilmi?
Uniqueness — duplicate ko‘p emasmi?
Timeliness / Freshness — ma’lumot eskirib qolmaganmi?
Validity — format va qoidalarga mosmi?
Balance — class yoki mavzular juda notekis taqsimlanmaganmi?
Mana shu savollarning har biri alohida quality dimension hisoblanadi.

Bu degani data manbalarini shunchaki tasodifiy aralashtirish bu xato.
Web      = 90%

Bu dataset bilan umumiy maqsadli model qilish mumkin lekin

Javob ko‘pincha yo‘q yoki juda kam bo‘lishi mumkin. Chunki modelning maqsadi coding bo‘lsa, training datasetda kodga oid data ulushi ham yetarlicha katta bo‘lishi kerak.

data mixture = model-design decision Bu degani Data mixture ham model dizaynining bir qismi degani
Ya’ni faqat layer soni,hidden size,attention heads,model parameters emas, balki modelga maqsadga qarab data tanlash ham model dizaynining bir qismidir.mana shular ham modelni qanday chiqishini belgilaydi.
Demak Qanday model xohlasak, dataset aralashmasini ham shunga mos tanlashimiz kerak.
Coding LLM uchun code data ko‘proq, ilmiy LLM uchun science data ko‘proq, umumiy LLM uchun esa data mixture kengroq va balansli bo‘ladi.
