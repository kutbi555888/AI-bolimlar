Yuqoridagi bu maxsus tokenlar Modelga matnning chegaralari yoki maxsus holatlarni tushuntirish uchun ishlatiladigan maxsus xizmatchi tokenlar hisoblanadi.

<eos> packing jarayonida hujjatlarni ajratish uchun shart.
Packing jarayoni — tokenlangan bir nechta qisqa hujjatlarni modelning context lengthiga mos bitta to‘liq sequence ichiga joylashtirish jarayoni.
trainingdagi bo‘sh joyni kamaytirib, GPU compute’dan samaraliroq foydalanish usuli.
hujjatlar orasiga odatda EOS token qo‘yiladi, shunda model bir hujjat tugab, boshqasi boshlanganini ajrata oladi.

0 ... 255 oraligida boladi.ya’ni 256 xil asosiy byte mavjud.Byte-level tokenizer shu 256 bytening barchasini ifodalay oladi. Shuning uchun notanish belgi chiqsa ham Notanish belgi - UTF-8bytelari -  bir nechta mavjud byte token

The Round-Trip Test

Matnni encode qilib ID ga o'girib, so'ngra decode qilganda aynan osha asl matn qaytib kelishini tekshiruvchi assert testi. 

Agar round-trip test buzilsa, demak ma'lumot yo'qolgan yoki tokenizer noto'g'ri ishlayapti. Bu test o'tmasa, keyingi qadamlar ma'nosiz boladi.

Qayerda ishlatiladi?
train_tokenizer.py skriptining eng oxirida, tokenizatorni yakuniy muzlatishdan (freeze) oldin majburiy tekshiriladi. 

Qanday ishlatiladi?
assert decoded_text == original_text kod satri orqali tekshiruv amalga oshiriladi. 

Analogiya 
Xatni o'zbekchadan inglizchaga tarjima qilib, keyin inglizchadan qayta o'zbekchaga o'girganda ma'no zarracha o'zgarmasligi tekshiruvi.

Keyin boshqa qism kerak bo‘lsa, o‘sha qism olinadi. Bu ayniqsa LLM trainingda katta .bin token fayllari bilan ishlaganda RAMni tejaydi.

Flat Sequence Packing without Padding
Qism B: Dataset Builder va Binary Format
Bu degani Hujjatlarni alohida blok qilib emas, balki orasiga <eos> qo'yib, bitta uzun tekis (flat) bir o'lchamli massiv shaklida birlashtirish.
barcha hujjatlarni EOS bilan ajratib, bitta uzun token oqimiga birlashtirish va undan fixed-length sequence’lar kesib olish; bo‘sh joyni PAD bilan to‘ldirmaslik.
Bu usulning asosiy foydasi — padding kamayadi, tokenlar isrof bo‘lmaydi va training compute samaraliroq ishlatiladi.GPU ko‘proq haqiqiy training tokenlari ustida ishlaydi.
PAD token — qisqa sequenceni kerakli uzunlikka yetkazish uchun qo‘shiladigan bo‘sh maxsus token.
Bu yerda <PAD> hech qanday ma’no bermaydi. U faqat sequence’larning uzunligini tenglashtirish uchun turadi.
Odatda attention mask orqali modelga:
Real token → ishlat
PAD token  → e’tibor bermagin
deb ko‘rsatiladi.
PAD token - bo‘sh joy to‘ldiruvchi maxsus token.
U modelga yangi ma’lumot bermaydi, faqat batchdagi sequence’larni bir xil uzunlikka keltiradi.
Shuning uchun packing without padding usulida imkon qadar PAD ishlatilmaydi va bo‘sh joyga boshqa haqiqiy tokenlar joylashtiriladi.

<pad> tokenlarini ishlatishga hojat qolmaydi. Hech qaysi token hisoblash jarayonida isrof bo'lmaydi, har bir token foydali training signal beradi. 

Qayerda ishlatiladi?
Dataset tayyorlash yakunida train.bin yaratilayotganda va batch shakllantirish jarayonida qo'llaniladi.

Qanday ishlatiladi?
Hujjatlar ketma-ket joylanadi. Block_size o'zgarganda datasetni boshqatdan qurish shart emas, chunki u tekis massiv, batch paytida kesiladi.

Input / Target Shifting
Qism B: Dataset Builder va Binary Format  

Bu degani Model keyingi tokenni bashorat qilishni o'rganishi uchun X (kirish) va Y (nishon) ma'lumotlarini 1 ta token farqi bilan siljitish. 
Input va Target Shifting — bu modelga hozirgi tokenlardan keyingi tokenni bashorat qilishni o‘rgatish usuli.
Masalan matn:
Men AI ni yaxshi ko‘raman
Tokenlar soddalashtirib:
[Men] [AI] [ni] [yaxshi] [ko‘raman]
qismlariga bolinadi.
Trainingda bundan ikkita ketma-ketlik qilinadi:
Input:
[Men] [AI] [ni] [yaxshi]

Target:
[AI] [ni] [yaxshi] [ko‘raman]
Ya’ni Target Inputdan 1 token chapga surilgan bo‘ladi.

Oqim:
Original tokenlar
↓
Input = tokenlarning oxirgisidan tashqari qismi
Target = tokenlarning birinchisidan tashqari qismi
↓
Model prediction
↓
Target bilan solishtirish
↓
Loss hisoblanadi 
↓
Backpropagation

Input = model ko‘radigan tokenlar.
Target = model keyingi token sifatida topishi kerak bo‘lgan javoblar.
Shifting = Targetni Inputga nisbatan 1 token surish.
Bu GPT kabi causal language modellarning asosiy next-token prediction training usulidir.

Causal Language Modeling asosi. T uzunlikdagi ketma-ketlikdan model 1 ta emas, balki bir vaqtning o'zida T ta training signal (loss) hisoblaydi. 

Qayerda ishlatiladi?
Training siklidagi DataLoader batch yaratish qismida: x = tokens[i:i+T], y = tokens[i+1:i+T+1]. 

Qanday ishlatiladi?
PyTorch orqali indekslar tasodifiy olinadi (torch.randint) va x hamda y massivlari 1 pozitsiya farq bilan kesib olinadi. 

Analogiya
Karaoke ekrani. Ekranda hozir aytilayotgan so'z (input) va undan keyingi keladigan va xonanda ko'zi bilan qidirayotgan so'z (target) siljishi.
