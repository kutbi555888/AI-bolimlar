Floating-point — kompyuterda kasrli, juda katta yoki juda kichik sonlarni ifodalash usuli.
Floating-point = sonni “asosiy raqamlar × daraja” ko‘rinishida saqlash usuli.


Dynamic Range - eng katta va eng kichik ifodalanadigan musbat sonlar oralig‘i.


Precision bu aniqlik


BF16 - Brain Floating Point 16(16 bit),   floating point turi


Underflow:
son format ifodalay oladigan eng kichik qiymatdan ham kichik bo‘lib qolishi.


Overflow:
son format ifodalay oladigan maksimal qiymatdan kattalashib ketishi.


Mixed Precision
Mixed = aralash. Precision = aniqlik.
Ya’ni training davomida bir nechta son formatidan birgalikda foydalanish degani


Memory Accounting nima?
Memory = xotira. Accounting = hisob-kitob.
modelni ishga tushirishdan oldin qancha GPU memory kerakligini hisoblash.


OOM = Out Of Memory - xotira yetishmasligi.
GPUga kerakli tensorlar sig‘masa CUDA out of memory xatosi chiqadi.


Activation - filter, kerakli malumotlarni otkazib keraksizlarini tashlaydi


Activation checkpointing / gradient checkpointing:
barcha oraliq activationsni memoryda saqlamasdan, faqat ayrimlarini saqlash va backwardda kerak bo‘lganlarini qayta hisoblash.



Checkpointingning mohiyati:
Ko‘proq activation saqlash  ko‘proq memory  kamroq qayta hisoblash 
Kamroq activation saqlash  kamroq memory  backwardda ko‘proq compute
Bu compute-memory trade-off deyiladi.


Trade-off
Bir narsani yaxshilash evaziga boshqasidan xarajat qilish yoki voz kechish


View nima?
View:
shu data storage’ni nusxalamasdan boshqa shape/index ko‘rinishida ko‘rish.


Clone - to‘liq nusxa yaratish.

Contiguous tensor - uzliksiz tensor

Matrix multiplication = matritsalarni ko‘paytirish.


FLOP = Floating-Point Operation = floating-point son ustidagi bitta matematik amal.
FLOPs - jami bajariladigan floating-point operatsiyalar.

Peak FLOP/s - Har GPUning nazariy maksimal tezligi.

GPU Communication = GPUlar/serverlar orasida ma’lumot almashish


Forward pass:
inputni model bo‘ylab oldinga o‘tkazib prediction/loss hisoblash.


Backward pass:
lossdan boshlab gradientlarni model bo‘ylab orqaga hisoblash.Bu backpropagation deyiladi.


Parameter Initialization nima?
Initialization = boshlang‘ich qiymat berish.
Trainingdan oldin weightlarni qanday sonlardan boshlash juda muhim.
Agar weightlar juda katta berilsa:
activations → qatlamdan qatlamga kattalashadi → exploding boladi(portlaydi va natijada sonlar juda kattalashib NaN yani son sifatida aniqlanmay qoladi),  NaN bu Not a Number — son sifatida aniqlanmagan natija.
Agar juda kichik bolsa:
activations/gradients → kichrayadi → vanishing boladi(sonlar juda kichrayib ketib gradient 0ga teng bolib model organmaydi)



Xavier Initialization - Maqsadi activation variance layerdan layerga haddan tashqari o‘zgarib ketmasin deydi.
Variance = dispersiya, qiymatlarning o‘rtacha atrofida tarqalishi.
yana bitta maqsadi:
weight hajmi dimensionga,olchamga mos kamaytirilmasa activations portlab ketishi mumkin.shuning uchun xavier initialization qollanadi


Reproducibility = tajribani qayta bajarib, bir xil/yaxshi taqqoslanadigan natija olish
